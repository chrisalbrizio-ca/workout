# Garage Protocol

Clean rebuild of Chris's personal fitness & recovery dashboard.

## Features (Current)
- Oura Ring integration (token saved in localStorage)
- Hourly auto-refresh when page is open
- Health Auto Export JSON loader (pointed at clean `Git` folder)
- Clean multi-file structure ready for GitHub

## Setup

1. Clone the repo
2. Open `index.html` in a browser
3. Paste your Oura Personal Access Token and save it
4. Use the Health Export button to load Apple Health data
